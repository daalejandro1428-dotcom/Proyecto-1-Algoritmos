# Proyecto-1-Algoritmos
# Integrantes: David Alejandro Calderon Palma
# Materia: Pensamiento Algoritmico
Introducción: Este proyecto es una aplicación de consola desarrollada en Python que permite organizar una agenda de películas para la semana. Entre sus principales funcionalidades, el usuario puede identificar la película más larga, calcular la duración promedio de las películas, buscar las más recientes, verificar cuántas están clasificadas para mayores de 18 años, modificar el horario de una película evitando solapamientos con otras y determinar si es posible llevar a un amigo según su edad. El código está modularizado en dos archivos: uno que contiene toda la lógica del programa y otro encargado de gestionar los menús e interacción con el usuario.
